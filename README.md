## 能做什么

- **任务与日程**：记录、分类、完成和修改任务，同时查看本周与下周；可开启通知卡和到期提醒。
- **记账**：收入与支出分类，日、周、月、年统计，明细和环形图切换。
- **辅导管理**：学生/项目档案、接单来源、排课、实际课时、应收与到账，收款可关联账本。
- **健身与专注**：常用运动与自定义项目、训练记录与统计；专注计时、分类、常用模板、实际时长统计、沉浸时钟、背景和三首离线轻音乐。
- **AI 助手**：用自己的 API Key 连接模型，聊天或执行操作分别选择；支持自动分类、增改查、完成和带确认的删除。可以上传图片/文档、整理待确认草稿、保存常用指令、按选定模块复盘并导出图表。
- **试用反馈**：执行报错/无法办理时可自动收集问题，也能手动补记；补充测试昵称与说明后导出 TXT/JSON，方便反馈与迭代。

模块可以在设置里按需开关，关闭模块保留已有记录。基础记录功能可离线使用；AI 需要联网和你自己的服务商账户，模型能力与费用取决于所选服务。

## 安装与更新

1. 下载上方 APK，在 Android 手机上允许当前下载来源安装应用，再打开安装包。
2. 已有弦记的用户直接覆盖安装，**不要先卸载或清除数据**。公开版沿用原包名和签名；已安全保存的 API Key 及本地记录可随覆盖更新保留。
3. 如需 AI，进入设置选择服务商/型号并填入自己的 Key；希望重启后继续使用时，勾选“在此设备安全保存”。安装包不附带任何人的 Key。
4. 建议定期把业务备份导出到设备外。普通业务备份不包含聊天、附件、问题记录及 Key；问题记录请单独导出。

最低 Android 7.0；建议更新 Android System WebView（90+）。目前主要在 Android12 测试环境验证，其他品牌/系统的省电、通知和到时亮屏可能存在差异。手机联动卡会打开相应应用，由你核对并保存。

0.6.1 与 0.6.0 功能一致，主要调整为关闭开发调试入口的公开发布构建；**问题记录与导出保留**。这仍是欢迎大家试用反馈的版本。
